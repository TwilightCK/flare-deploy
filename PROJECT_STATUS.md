1. **Get Test Tokens**
   - Visit: https://faucet.flare.network/
   - Select Coston2 Testnet
   - Request FLR tokens

2. **Configure Private Key**
   - Open .env file
   - Add your MetaMask private key
   - Save the file

3. **Deploy**
   ```bash
   cmd /c "npm run deploy"
   ```

4. **Run Frontend**
   ```bash
   cmd /c "npm run frontend"
   ```

5. **Test**
   - Open http://localhost:3000
   - Connect wallet
   - Join queue
   - Play game!
