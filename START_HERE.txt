📋 QUICK START (5 MINUTES):

1️⃣  GET TEST TOKENS (1 min)
   → Go to: https://faucet.flare.network/
   → Select "Coston2 Testnet"
   → Paste your wallet address
   → Get free FLR tokens

2️⃣  ADD YOUR PRIVATE KEY (30 sec)
   → Open .env file
   → Replace "your_private_key_here" with your MetaMask private key
   → Save the file

3️⃣  CHECK SETUP (10 sec)
   → Run: cmd /c "npm run check"
   → This will verify everything is ready

4️⃣  DEPLOY CONTRACTS (1 min)
   → Run: cmd /c "npm run deploy"
   → Copy the contract addresses (will be shown)
   → Frontend .env will be auto-updated!

5️⃣  RUN THE APP (30 sec)
   → Run: cmd /c "npm run frontend"
   → Open: http://localhost:3000
   → Connect your wallet and play!
